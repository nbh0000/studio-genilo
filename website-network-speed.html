DNS와 서버 연결

DNS는 도메인을 IP 주소로 찾는 시간이고 TCP는 서버와 연결을 만드는 시간입니다. 특정 지역에서만 느리다면 DNS 사업자, CDN과 서버 배포 위치를 함께 확인합니다.

TLS와 HTTPS

TLS는 암호화 연결을 협상하는 단계입니다. 인증서 체인, 프로토콜과 서버 위치가 영향을 줄 수 있으며 HTTPS 자체를 없애는 방식이 아니라 최신 설정과 연결 재사용으로 개선해야 합니다.

TTFB와 HTML 다운로드

TTFB는 요청 후 첫 바이트가 도착하기까지의 시간으로 서버 처리와 캐시의 영향을 많이 받습니다. 첫 응답은 빠른데 다운로드만 느리면 HTML 크기, 압축과 전송 처리량을 확인합니다.
