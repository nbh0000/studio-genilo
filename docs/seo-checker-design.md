# SEO checker extension

Mode: Operate / Read. Preserve Studio Genilo's existing dark violet identity.
Audience: site owners deciding which technical and editorial changes to make.
Primary action: analyze a URL with an optional target query; read evidence and a purchased guide.

- Base #171717, surface #202024, text #f0f0f8, secondary #b8b8c5, accent #c86df0, error #ff7b87.
- Reuse --font-sans (Pretendard Variable). Body 16px/1.7, secondary 14px, section titles 22px. Korean word-break: keep-all; URLs may wrap anywhere.
- Reuse --max: 1180px. Form max 860px, report prose max 76ch. Spacing 8/12/16/24/32px; controls minimum 44px.
- One primary URL action. Query and page type visible; audience, region and comparison URLs in native details.
- The report is a reading surface: findings separated by rules, evidence next to recommendation. No fabricated scores for editorial quality or rank predictions.
- Breakpoints: single column below 640px, flexible two-column input above; validate 375/768/1024/1440px.
- Inaccessible or unmeasured data stays visibly unknown. Loading never pretends to know completed server stages.
- Purchase amount 150,000 KRW per immutable report. Access is server-enforced. No hidden paid content in HTML, preview payloads, export or storage.
- Use native disclosure, visible focus, reduced motion and announced request/error states. No new animation or imagery required.
- Page-specific official-update evidence belongs to the authorized guide. Free API coverage exposes review dates, counts and status labels only. Review dates and manual-check limits must remain distinct from the inspected site's result.

- Score cards show technical scores for Naver/Google/GEO and a separately labeled AEO content-structure diagnostic score. Preserve unknown/N/A in evidence, exclude them from score denominators, and show unavailable scores as “— / 측정 불가”.
- Omit the redundant assessment headline (additional checks or review counts) from all score cards; retain status counts and strongest/priority findings. Explain AEO score scope inside the expanded results.

## Public recent diagnoses

- Extend the existing Operate surface between the URL form and results. One horizontal list holds up to 20 actual recent records; it is a browsing strip, not a leaderboard.
- Reuse the dark base, --guide-surface, --guide-text, --checker-accent, --font-sans and 12px radius. Cards use a single border, 20px padding, a 16px title and compact four-column score labels. Use 16px gaps, 44px arrow controls and tabular numerals; no automatic motion or new imagery.
- Keep the section heading left aligned and the two real stored totals alongside it on wide screens, stacked below at narrow widths. Card width is 304px on desktop and at most the available viewport minus a small next-card preview on mobile. Confine overflow to the list; Korean words stay intact and URLs may break anywhere.
- Public fields are the sanitized target URL, title, check time and four scores. Displayed URLs open in a new tab with an accessible label; query strings and fragments are omitted. Private guide content and account data never enter cards. Explain public fields beside the form before submission.
- Loading, genuinely empty, unavailable and retry states use explicit text. Unknown scores are an em dash with a “측정 불가” accessible name. Missing totals never appear as zero; totals describe saved public records and distinct hostnames.
- Provide native swipe/scroll, previous/next buttons, list-level arrow/Home/End keys and visible focus. Links remain normal keyboard and new-tab navigation. Refresh the list after a successful check without moving focus or the page scroll.
- New results show every active check label and status with all four categories expanded; filters and collapse controls remain available for deliberate inspection. The free view and its exports never include evidence, repair instructions or page-specific source references, even when a purchased report is restored.
- When all four raw scores are exactly 100, the response is complete HTTP 200 and no confirmed failure or indexing blocker exists, replace improvement quotes and their result CTA with “개선이 필요없습니다.” and the scope sentence. Unknown scores or a rounded display of 99.9 never qualify; other results retain existing prices and consulting options.
